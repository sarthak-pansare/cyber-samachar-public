# Cyber Samachar website source

This is a public source snapshot of the Cyber Samachar website. It contains the Next.js application and database schema from the private project's `main` branch. Internal operations, project notes, historical demos, credentials, and the private repository's Git history are not included.

To run it locally, install the packages with `npm ci`, copy `.env.example` to a local `.env.local`, and provide your own service settings. Then run `npm run dev`. The example file contains no working credentials.

This snapshot is for code review and development. It is not connected to the live Cyber Samachar deployment.
